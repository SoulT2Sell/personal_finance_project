
## 📦 Django Apps

| App            | Responsibility                                      |
|----------------|-----------------------------------------------------|
| `users`        | Custom user model, authentication, profiles         |
| `accounts`     | Bank accounts, cash wallets, credit cards           |
| `categories`   | Income & expense categories (can be hierarchical)   |
| `transactions` | All money in/out movements (core model)             |
| `budgets`      | Monthly / period budget limits linked to categories |
| `dashboard`    | High-level overview, aggregated data for charts     |
| `ai`           | AI tools, chat interface, automatic insights        |
| `api`          | DRF routers and viewsets                            |

> **Note:** Pure calculation logic (balance, income, expenses, statistics) lives in a `services/` package, not inside models or views.

## 🛠️ Development Phases

### Phase 1 – Core Foundation
- Django project setup
- Custom User model (`users`)
- Accounts (`accounts`)
- Categories (`categories`)
- Transactions (`transactions`)
- PostgreSQL database
- Basic Django Admin

### Phase 2 – Financial Engine
- Services layer for calculations
- Balance calculation
- Income & Expenses aggregation
- Budgets (`budgets`)
- Reports & Statistics

### Phase 3 – Web UI
- Templates
- Beautiful dashboard
- Charts (Chart.js / ApexCharts / etc.)
- Responsive design

### Phase 4 – API (Django REST Framework)
- `/api/accounts/`
- `/api/transactions/`
- `/api/categories/`
- `/api/budgets/`
- `/api/dashboard/`
- `/api/reports/`
- Authentication (JWT or Token)

### Phase 5 – AI Layer
- AI tools (`get_balance`, `get_monthly_income`, `get_monthly_expenses`, ...)
- AI chat interface
- Automatic insights
- Dashboard summaries generated by AI

### Phase 6 – Desktop Application (Optional)
- Desktop client (Electron / Tauri / PyQt / etc.)
- Consumes the project API
